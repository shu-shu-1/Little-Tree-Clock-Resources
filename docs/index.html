小树时钟 API 文档

小树时钟静态 API 文档。所有端点均返回 JSON 格式数据。

Base URL

https://clock.api.zsxiaoshu.cn/
GET

根索引

返回 API 的总体索引，包含各端点路径。

/index.json

响应示例 / Response Example

{
  "name": "Little Tree Clock Resources API",
  "version": "1",
  "base_url": "https://clock.api.zsxiaoshu.cn/",
  "endpoints": {
    "index": "index.json",
    "update": "update/latest.json",
    "plugins": "plugins/index.json",
    "announcements": "announcements/index.json"
  }
}
字段 类型 说明
namestringAPI 名称
versionstringAPI 版本
base_urlstring所有端点的基础 URL
endpointsobject端点路径映射
GET

更新 API

返回最新版本的元数据（不含安装包本体）。

/update/latest.json

响应示例 / Response Example

{
  "version": "1.0.0",
  "release_date": "2026-03-03",
  "download_url": "https://github.com/shu-shu-1/Little-Tree-Clock/releases/download/v1.0.0/LittleTreeClock-1.0.0.zip",
  "changelog_url": "https://github.com/shu-shu-1/Little-Tree-Clock/releases/tag/v1.0.0",
  "min_version": "0.1.0",
  "mandatory": false
}
字段 类型 说明
versionstring最新版本号
release_datestring发布日期 (YYYY-MM-DD)
download_urlstring安装包下载地址
changelog_urlstring更新日志页面
min_versionstring支持自动升级的最低版本
mandatoryboolean是否为强制更新
GET

插件商店 API

获取插件列表

返回所有插件的元数据列表（不含插件源码本体）。

/plugins/index.json

响应示例 / Response Example

{
  "plugins": [
    {
      "id": "example-plugin",
      "file": "example-plugin.json"
    }
  ]
}
字段 类型 说明
idstring插件唯一标识符
filestring插件详情 JSON 的文件名

获取插件详情

返回指定插件的详细元数据。

/plugins/{id}.json
字段 类型 说明
idstring插件唯一标识符
namestring插件名称
descriptionstring插件简介
versionstring插件版本号
authorstring作者
download_urlstring.py 文件下载地址
homepagestring插件主页或详情页
tagsarray[string]标签列表
supported_osarray[string]支持的操作系统 (windows/macos/linux)
updated_atstring最后更新日期
min_app_versionstring所需最低应用版本
GET

公告 API

返回所有公告的完整内容。

/announcements/index.json

响应示例 / Response Example

{
  "announcements": [
    {
      "id": "1",
      "title": "欢迎使用小树时钟！",
      "content": "小树时钟现已支持插件商店与自动更新功能，欢迎体验！",
      "date": "2026-03-03",
      "level": "info"
    }
  ]
}
字段 类型 说明
idstring公告唯一 ID
titlestring公告标题
contentstring公告正文（完整内容）
datestring发布日期 (YYYY-MM-DD)
levelstring级别: info / warning / error

如何维护

1 发布新版本

编辑 update/latest.json，更新 version、release_date、download_url 等字段，并将新版安装包上传至 Releases。

2 上架新插件

  1. 在 plugins/ 目录下创建 {id}.json，填写插件元数据
  2. 将对应 .py 文件上传至 plugins/files/ 目录
  3. 将该插件条目追加到 plugins/index.json 的 plugins 数组中

3 发布公告

在 announcements/index.json 的 announcements 数组中追加一条新记录，id 递增，level 可选 info、warning 或 error。
